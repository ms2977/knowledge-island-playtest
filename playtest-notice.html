一起探索，也安心試玩

知識探索島・試玩須知與素材來源
更新：2026 年 11 月 15 日

歡迎家長分享遊戲網址，陪孩子選好年級與練習範圍。這是持續修正的學習冒險試玩版，題目與判定可能仍有錯誤；遊戲結果供練習參考，不是正式能力診斷，也不保證學習成效。

開始之前

  • 目前提供一、二、五、六年級內容。一年級已有國語、數學、生活、六章主線與迷宮；進一步主題由家長依學習進度加入。三、四年級尚未開放，請勿以鄰近年級代替。請使用暱稱，確認孩子與年級後再登錄錯題。
  • 不必申請 GitHub 帳號。建議從 LINE 選擇「以外部瀏覽器開啟」，之後固定使用同一個 Chrome、Safari 或 Edge，避免換瀏覽器找不到進度。
  • 由家長協助安排時間，可以隨時休息。卡關或題目有疑問時，先回報，不必反覆猜答案。

進度、照片與隱私

  • 角色暱稱、年級、練習紀錄、手動輸入的錯題與遊戲進度保存在這台裝置的瀏覽器。遊戲沒有帳號雲端同步，也沒有把這些紀錄送到遊戲伺服器的功能。
  • 家長選取的錯題照片只作當頁對照，不儲存、不上傳；目前沒有自動圖片辨識。
  • 換裝置、清除網站資料或使用無痕模式，可能找不到原進度。請到家長區「資料與系統」自行匯出備份；備份含學習資料，請私人保存。共用裝置上的其他使用者也可能看到存檔，家長區不是私人帳號隔離。
  • 遊戲未加入廣告或流量追蹤碼；網站由 GitHub Pages 提供，主機服務仍可能處理 IP、裝置及連線紀錄，詳見 GitHub 隱私聲明。這不等於整個網路連線完全不產生紀錄。
  • 朗讀使用瀏覽器／系統提供的語音引擎，是否使用網路由裝置與語音服務決定。畫面可按「停止朗讀／停止播放」。

怎麼回報問題

可按遊戲畫面角落的「回報這個畫面」，先查看再複製版本、年級、位置、題目或對話代號、題型、瀏覽器種類與畫面寬度；不包含姓名、答案或存檔，沒有自動傳送。請由家長向分享遊戲給你的家長回報：年級、章節或題目位置、按了哪個按鈕、預期與實際結果、裝置與瀏覽器。截圖前遮住姓名、學校、班級與其他個資；請勿在群組貼整份孩子備份或完整試卷。這個頁面沒有回報上傳表單，不會自動收集回報資料。
