# 知識探索島 試玩版

版本：playtest-20261109-g6。這是可獨立部署的靜態遊戲，首頁為 index.html。

- 請以網站網址遊玩；本機預覽可在此資料夾執行 `python -m http.server 8080`，再開啟 http://localhost:8080。
- 進度保存在各自的瀏覽器，沒有雲端帳號同步。搬網址、換裝置或清除瀏覽器資料前，請先到家長區匯出備份，再於新網址匯入。
- 六年級新增 162 題原創情境任務：數學 108 題（含五年級先備 21 題）、國語 54 題。二年級內容保留，各年級分開出題。
- 家長區「練習設定」可隨時調整單元、學期、難度及五年級先備開關。新增題預設避免重複；用完後可選其他單元，或明確開啟重複複習。
- 專用專案：ms2977/knowledge-island-playtest，與其他系統分開；完整開發原始碼、審核紀錄和交接文件保留在桌面正式專案。
- 手機可使用瀏覽器的「加入主畫面」。已附圖示，但未提供 Service Worker 或離線更新功能；安裝介面依瀏覽器而異。
- GitHub Pages：將此資料夾的內容放在專用儲存庫根目錄，Settings → Pages → Deploy from a branch → main / (root)。首頁不能多包一層 site 資料夾。
- 公開網址可分享給親友；頁面沒有存取密碼。不要上傳孩子的匯出存檔、考卷、金鑰或整個開發專案。
- React / ReactDOM 授權見 THIRD_PARTY_LICENSES.txt。遊戲文字與美術不因存放於公開儲存庫而自動授權他人再利用。
